Timetable Generator Website (Under Construction)
Project Overview:
A full-stack web application developed as part of a System Analysis and Design (SAD) and Software Engineering academic project. The system is designed to streamline and automate the academic scheduling process, providing a user-friendly interface for students to manage their course timings.

Technical Stack:
Framework: MERN Stack (MongoDB, Express.js, React.js, Node.js).
Core Features & System Design:
Algorithmic Schedule Generation: The core system is designed to process academic constraints and automatically generate multiple valid timetable variations and options.
Student-Centric Workflow: The primary user experience focuses on the student's role within the system. Instead of building a schedule from scratch, students can review the pre-generated timetable options and select the one that is most convenient for their personal routine.
Current Status:
Under Construction: The application is currently in the active development and implementation phase.
